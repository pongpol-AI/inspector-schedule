เริ่มจากไฟล์ตารางของคุณ

ประมวลผลในเบราว์เซอร์ ไฟล์ Excel ไม่ถูกอัปโหลดหรือเก็บบนเซิร์ฟเวอร์

ยังไม่ได้เลือกไฟล์ • เลือกได้จากทุกโฟลเดอร์ในเครื่องหรือไดรฟ์ที่เข้าถึงได้

รองรับ .xlsx และ .xls • เลือกไฟล์ → เลือกแท็บเดือน → ดูและดาวน์โหลดการ์ด

รูปแบบตารางที่รองรับ

หัวตารางภายใน 20 แถวแรก: โรงพยาบาล (หรือหน่วยงาน), จังหวัด, การนัดหมาย (หรือวันที่ตรวจ/วันที่), หัวหน้าทีม และผู้ตรวจ1, ผู้ตรวจ2 … รองรับวันที่ Excel และวันที่ภาษาไทย แถวที่ไม่มีวันนัดหรือระบุเลื่อนจะถูกข้าม
